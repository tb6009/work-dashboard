왕초보 에이전트만들기

문서 한 편을 읽고 핵심 정보를 나누고, 서로 다른 정보구조의 인포그래픽으로 바꾸는 에이전트를 만드는 수업과제 기록이다. 결과만 선별하지 않고 첫 변환부터 표현 방식 비교, 가로형 확장, 전체 문서 적용까지 실제 출력 순서대로 정리했다.

과제 이미지23
수업 설계 자료01
전체 고유 이미지24
제작 단계05
수업과제임을 명시함
이 페이지는 교육 과정에서 제작한 실습·과제 기록이며, 기업 납품이나 실제 운영 성과를 의미하지 않는다. 공개용 이미지에서는 조직을 식별할 수 있는 표식을 가렸다.

작업 프로세스

처음부터 자동화하지 않았다. 원문 구조를 직접 나누고, 한 장을 여러 방식으로 만들어 비교한 뒤, 가로형 규격과 전체 문서로 확장했다. 마지막에는 이 순서를 에이전트의 작업 규칙으로 정리했다.

01

원문 구조 나누기

목표·범위, 분리와 통합, 운영 흐름처럼 페이지마다 다른 정보 관계를 먼저 확인했다.

02

첫 변환 만들기

텍스트와 수치는 코드 기반으로 배치하고 이미지가 정보 정확성을 대신하지 않게 했다.

03

표현 방식 비교

맥락형, 단일 생성형, 타입 시스템형과 단순·균형·상세 구성을 나란히 만들었다.

04

전체 문서로 확장

선택한 가로형 규격을 나머지 페이지에 적용하고 원문에 없는 수치와 식별자를 제거했다.
