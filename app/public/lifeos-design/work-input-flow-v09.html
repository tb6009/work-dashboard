정리 — 무엇을 하면 무엇이 되는가

동작결과
프로젝트 블록의 「+ 한 줄」 탭그 자리가 입력창이 됨. 프로젝트·날짜는 자동 지정
엔터저장 + 목록 맨 위에 추가. 입력창은 열린 채 비워짐 → 연속 입력
완료 또는 바깥 탭키보드 내려가고 입력창 닫힘. 저장 버튼 없음
쓰다가 화면을 벗어남쓰던 내용은 임시 보관. 다시 열면 그대로 있음
하단 공용 입력창에 쓰기문장에서 프로젝트를 추정해 칩이 옅게 켜짐
칩을 직접 누름추정을 무시하고 그 프로젝트로 고정
아무 칩도 안 켜진 채 엔터저장 안 됨. 「어디에 넣을까요」를 물어봄
저장 직후 검은 띠 「바꾸기」3초 안에 누르면 프로젝트 다시 고름
줄을 왼쪽으로 밀기삭제. 자동 유입 줄은 숨기기로 표시
본문에 → 를 넣음뒤쪽이 「다음 할 일」로 따로 저장 (예: 서론 재배치 → 다음은 방법론)
프로젝트 이름 탭그 프로젝트만 펼쳐 전체 이력 보기
설계 원칙 하나 — 이 화면에는 「저장」 버튼이 없습니다. 지금 Work·Thesis 탭은 다 쓰고 저장을 눌러야 남습니다. 저장을 안 눌러 날아간 경험이 한 번이라도 있으면 그 화면은 안 쓰게 됩니다. 엔터가 곧 저장이고, 쓰다 만 것은 임시 보관됩니다.
아직 정할 것 — ① 프로젝트당 기본으로 몇 줄까지 보일지(지금 시안은 2~3줄)  ② 자동 유입 줄을 고칠 수 있게 할지(권장: 읽기전용)  ③ 프로젝트 정렬을 최근순으로 할지 건수순으로 할지
