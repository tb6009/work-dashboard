연구 1 권장모형과 설문 재구성안

2026-10-05 / v0.3 / 채택 전 검토안. 문항 예시는 배포용 검증척도가 아니다.

1. 제안 범위

권장 SVG를 작성했다. 현재 기준인 24번 v0.2의 변경 승인으로 간주하지 않는다. 기존 설문과 연구 2는 보존한다.

앞선 검토의 단정적 제안을 조정한다. TC1과 JE의 중복은 위험이지 판별 실패가 확인된 결과는 아니다. GAIL 조절이 EXP 조절보다 근거가 강하다고 확인하지 않았다. 조절 수를 1~2개로 제한하는 것도 통계적 법칙이 아니다. 표본·효과크기·측정오차에 따라 판단한다. GAIL 하위영역의 임의 선택도 현재 권고하지 않는다.

이번 제안은 기존 프로젝트 문서와 문항을 이용한 설계안이다. 새로운 외부 문헌 검증은 수행하지 않았다. 원척도 신뢰도 수치를 재인용하거나 새 척도의 타당성을 주장하지 않는다.

2. 모형과 분석 역할

요소 권장 검토안 채택 전 조건
USE → TC → TP·JE·WI 병렬 결과 구조 유지 TC–JE 개념·측정 구분
USE → TP·JE·WI 직접경로 함께 추정 직접효과 유의성으로 매개 유형을 단정하지 않음
USE×GAIL → TC 핵심 조절 후보로 우선 검토 경로 기제와 GAIL 측정구조 확인
EXP → TP·JE·WI 직접 예측변수로 포함하는 후보 조절 삭제가 통제의 충분성을 뜻하지 않음
TC×EXP → 세 결과 사전 지정한 탐색 후보 이론·검정력 확보 시 확증가설로 재검토
INC_AI 별도 보조 분석 AI 소득 영향과 실제 소득 변화를 구분

GAIL 주효과는 TC 방정식에 포함한다. EXP는 객관적 숙련도나 AI 사용 이전 능력이 아닌 자기평가 직업 전문성이다. 다른 공통 원인 경로는 인과도식으로 검토한다. 모든 배경변수를 자동 통제하지 않는다.

T = a0 + a1 U + a2 G + a3 U×G + 사전 지정 공변량 + eT
Yk = bk0 + bk1 T + ck U + dk E + 사전 지정 공변량 + ek
Yk ∈ {TP, JE, WI}
탐색 확장: Yk 방정식에 hk T×E 추가

선형 모형의 기본 간접 관련성은 (a1+a3G)bk1이다. EXP 조절 확장에서는 (a1+a3G)(bk1+hkE)다. 두 모형의 추정값을 혼용하지 않는다. 결과들의 잔차 공분산을 허용하는 방안을 검토한다. 횡단자료는 이 식의 시간적 인과과정을 입증하지 않는다.

3. 선택 가능한 설문 운영안

안 구성 이점 부담·실패 시 처리
A. 기존 TC 유지 + JE 개발 — 우선 검토 TC4·TP3·IDS-WI 후보 유지, JE만 우선 개발 기존 문항과의 추적성, 연구 질문 유지 TC를 확장·도전 행동으로 제한. JE 판별 실패 시 주모형 채택 보류
B. TC와 JE 동시 재개발 TC를 일반적 과업 재설계로 재정의하고 새 문항 개발 단순화·통합·재배분도 포괄 가능 두 척도 동시 개발 부담. 기존 TC 검증을 승계할 수 없음
C. JE를 탐색 결과로 유보 TP·WI를 주분석, JE는 개발·보조 분석 검증되지 않은 JE가 주모형 전체를 좌우하는 위험 감소 직무확대는 확증 결론에서 제외. 실패 후 사후 변경이 아닌 사전 분기 기준 필요

권장은 A안을 먼저 준비하고, 내용 검토에서 구분이 실패하면 C안을 선택하는 절차다. B안은 일반적 재설계가 연구 목적에 필수일 때 선택한다. TV·SV를 주모형에 복귀시키지 않는다.

4. 변수별 조정

변수 현재 문항의 의미 재구성 제안
USE4 정보·아이디어·문제해결 중심 사용 유지 시 정의를 이 범위로 한정. ACT 제작·수정은 별도 보조지표로 유지
TC4 과업 추가·복잡성·도전·어려운 결정 확대 A안에서는 유지·기간 번안 검토. TC1만 임의 삭제하지 않음
TP3 시간 절약·생산성·수행 가능량 기여 명칭 유지. 실제 효율 변화나 객관적 성과로 부르지 않음
JE 과업 종류·범위의 회고적 확대 후보 증가만 묻는 문항과 양방향 변화형을 비교하여 선택
WI5 업무강도 증가 기간 번안과 WI5 프리랜서 적합성 우선 검토
GAIL17 5개 하위영역의 자기평가 문항 유지 후 구조 검토. 총점·고차요인 선택 근거 필요
EXP5 자기평가 전문성 기존 응답 6점 유지 후보. 경력연수와 대체·합산 금지
INC_AI1 AI의 지각된 소득 영향 기존 3범주 또는 제안 5범주 중 하나 선택. 코드 대응표 작성

USE를 제작·수정까지 포괄하는 일반 사용량으로 바꾸려면 별도 조작화가 필요하다. ACT4를 USE4에 더해 하나의 반영형 척도로 간주하지 않는다. 활동을 하지 않음과 활동은 하지만 AI를 사용하지 않음을 구분한다.

5. TC 문항 선택

A안에서는 기존 TC4를 전문가·인지면담에 그대로 제시한다. 각 문항에 대해 행동의 자발성, 과업 수와 종류의 구분, JE와의 중복을 확인한다. 명칭은 ‘과업 크래프팅 행동’으로 두고 확장·도전 중심이라는 해석 범위를 명시한다. 모형에 접근/회피 하위변수를 추가하지 않는다.

B안의 예시 문항은 다음과 같다. 모두 연구자 작성 초안이며 기존 TC의 번역이 아니다.

  • 업무 목표를 달성하기 위해 과업의 수행 순서를 스스로 조정했다.
  • 과업 사이의 연결 방식을 스스로 바꾸었다.
  • 반복되는 과업의 수행 절차를 스스로 재구성했다.

이 예시는 작업방법 개선이나 프로세스 혁신과 겹칠 수 있다. 기존 TC의 과업 경계 변경을 충분히 포괄하는지도 확인해야 한다. 문장만 교체하여 원척도 이름을 유지하지 않는다.

6. JE 문항은행과 응답

공통 문두 후보: ‘생성형 AI를 업무에 정기적으로 활용하기 시작하기 전과 비교해, 현재 담당하는 디자인 업무를 생각해 주세요.’

‘정기적 활용’의 해석과 기준 시점 기억 가능성은 인지면담에서 확인한다. AI 사용 전 유급 디자인 경험이 없는 사람은 비교 불가로 구분한다.

JE-A: 확대 정도형

  1. 내가 담당하는 디자인 과업의 종류가 더 다양해졌다.
  2. 내가 담당하는 디자인 업무의 범위가 넓어졌다.
  3. 하나의 디자인 프로젝트에서 내가 담당하는 업무 단계가 늘어났다.

응답 후보: 전혀 그렇지 않다 / 별로 그렇지 않다 / 보통이다 / 대체로 그렇다 / 매우 그렇다. 판단 어려움은 별도 선택이다. 연구자 설계 응답이며 원척도 앵커가 아니다.

낮은 점수로 축소와 불변을 구분할 수 없다. 3번은 프로젝트 방식에 따라 해당하지 않을 수 있다. 세 문항을 모두 채택하거나 단일요인으로 확정한 것은 아니다.

JE-B: 양방향 범위 변화형

각 항목에 공통 문두를 적용한다.

  1. 담당하는 디자인 과업 종류의 수
  2. 담당하는 디자인 업무의 전체 범위
  3. 한 프로젝트에서 담당하는 업무 단계의 수

응답 후보: 크게 줄었다 / 다소 줄었다 / 변화 없다 / 다소 늘었다 / 크게 늘었다. 판단 어려움과 해당 없음은 별도 선택이다.

JE-B는 축소·불변·확대를 구분하지만 변수 정의를 ‘지각된 과업범위 변화’로 조정해야 한다. 양의 점수만으로 척도를 절단하지 않는다. JE-A와 JE-B를 한 점수로 합치지 않는다. 인지면담에서 비교한 후 본조사에는 한 방식을 채택한다.

별도 진단 문항

  • 이전에 맡지 않던 종류의 과업을 새로 맡게 되었습니까?
  • 이전에 맡던 종류의 과업 중 현재 맡지 않는 과업이 있습니까?

새로운 과업의 발생은 과업 교체일 수도 있다. 위 두 항목은 JE 핵심 점수에 자동 합산하지 않는다. ‘다른 전문가가 하던 일’도 역할 침범이나 외주 내재화만 측정할 수 있어 보조 탐색으로 둔다.

7. 기간 설계

일회 설문에서 모든 변수를 동일 기간으로 바꾼다고 인과 순서가 확보되지는 않는다. 실행 가능한 안은 최근 행동과 장기 회고 결과를 함께 측정하되 관련성으로 해석하는 것이다.

블록 검토할 기간 주의
USE·ACT·TC 최근 3개월 후보 TC 원문의 1주를 바꾸는 번안. 회상 가능성을 먼저 확인
TP 최근 3개월 업무에서 경험한 AI 기여 후보 긍정 기여의 정도. 생산성 감소 측정 불가
JE·WI 정기적 AI 사용 이전 대비 현재 후보 노출 기간이 사람마다 다름. WI 원문 5년을 변경하는 번안
EXP·GAIL 원척도 문두 우선 보존 AI 이전 능력으로 해석하지 않음

최근 3개월은 이 문서의 설계 후보이며 확정된 권장 회상기간이 아니다. TC의 일주일 기준을 유지하는 안도 비교한다. AI 정기 사용 시점, 사용 중단, 이직·역할 변경, 비교 가능한 사용 전 경험을 확인한다. 짧은 사용기간을 처리할 규칙은 본조사 전에 정한다.

최근 TC가 과거 누적 변화를 발생시켰다고 해석하지 않는다. 시간 순서가 연구의 핵심이면 기준선과 후속 결과를 포함한 종단설계를 별도 검토한다. 단순히 두 번 조사하는 것만으로 매개 인과성이 확보되지는 않는다.

8. WI·소득 응답 조정

WI1–WI4는 기존 번역 초안으로 인지면담을 수행한다. WI5의 ‘직원 감소’는 혼합 표본에서 직접 확인한다. 프리랜서의 해당 없음을 중립값이나 0으로 넣지 않는다.

가능한 안은 공통 문항으로 단축형을 개발하고 WI5를 직원 전용 보조 문항으로 두는 것이다. 이 경우 수정 척도의 새 검증이 필요하다. 직원은 5개, 프리랜서는 4개 평균을 내어 곧바로 같은 점수로 비교하지 않는다. 집단 비교는 비교 가능한 측정구조를 확인한 뒤 수행한다.

WI는 증가에 동의하지 않는 응답만으로 부담 완화를 검출할 수 없다. 감소까지 연구질문에 포함하려면 별도 양방향 변화 문항을 개발한다. TP·JE·WI 점수를 빼서 순이득 점수를 만들지 않는다. JE 확대도 그 자체로 이득 또는 비용을 뜻하지 않는다.

INC_AI 문두 후보: ‘생성형 AI를 업무에 활용한 것이 현재 디자인 업무소득에 어떤 영향을 미쳤다고 생각하십니까?’

  • 보수적 선택: 감소 / 영향 없음 / 증가.
  • 세분 선택: 크게 감소 / 다소 감소 / 영향 없음 / 다소 증가 / 크게 증가.
  • 공통 별도 선택: 판단 어려움 / 응답 거절.

세분 선택은 연구자 번안이다. 서열모형 사용 시 가정과 범주별 표본을 확인한다. 기존 REW_AI와 새 INC_AI의 코드 대응을 기록한다. 실제 소득 변화가 없다는 뜻으로 해석하지 않는다.

9. 설문 배치와 연구 2 연결

  1. 참여 동의·유급 디자인 업무·AI 사용 경험을 확인한다.
  2. 고용형태·디자인 분야·사용 시점·비교 가능성을 묻는다.
  3. USE·ACT를 제시한다.
  4. TC를 제시한다.
  5. TP·JE·WI를 독립된 안내문과 함께 제시한다.
  6. EXP·GAIL을 제시한다.
  7. INC_AI와 필요한 배경정보를 제시한다.

주모형의 방향을 설문 안내문에 설명하지 않는다. 블록 순서와 응답 피로는 파일럿에서 확인한다. 연구 1 단독 구성의 후보 핵심 문항 수는 USE4+TC4+TP3+JE3+WI5+EXP5+GAIL17+INC1=42개다. ACT4 포함 시 46개이며, 배경·분기·진단 문항은 별도다. JE와 WI 확정에 따라 수가 바뀐다.

통합 설문에서는 USE·EXP·GAIL을 연구 2와 한 번만 측정한다. 이 공유 변수의 문두·기간 변경은 연구 2에도 영향을 준다. 연구 1 변경을 이유로 SC·THR을 삭제하지 않는다. IWB·TV·SV의 실제 수집 여부도 연구 2와 기존 비교계획을 확인한 뒤 결정한다.

10. 검증 순서와 채택 기준

  1. TC·JE·WI의 정의와 문항 대응표를 작성한다. 개념 중복이 남으면 JE 주경로를 확정하지 않는다.
  2. 전문가 내용 검토와 직원·프리랜서 인지면담을 수행한다. JE-A/B, 기준 시점, WI5를 비교한다.
  3. JE 구조를 탐색하고 가능한 독립 표본 또는 별도 단계에서 확인한다. 동일 자료의 탐색·확인을 독립 검증이라고 부르지 않는다.
  4. 전체 측정모형의 신뢰도·수렴·판별성과 집단별 적용성을 확인한다. 특정 지표 하나로 개념 구분을 확정하지 않는다.
  5. 조절효과·간접 관련성의 검정력과 표본을 산정한다. 효과크기를 아직 정하지 않았으므로 표본 수를 확정하지 않는다.
  6. 주분석·탐색분석, 결측, 범주형 소득 분석, 다중검정, 통제집합을 사전 기록한다.
  7. 수정안을 승인한 후 설문 배포본과 온라인 폼을 갱신한다.

반대 설명도 유지한다. 높은 WI가 AI 사용과 TC를 촉진할 수 있다. 외부 요구가 TC와 JE를 함께 높일 수 있다. 높은 EXP는 AI 효과를 증폭하거나 낮출 수 있다. 현재 자료로 방향을 판정할 수 없다.
