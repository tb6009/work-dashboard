4. 유지해야 할 사용자 결정

연구모형

연구 1: USE → TC → TP·JE·WI. 세 결과는 병렬이다. GAIL은 USE→TC를 조절한다. EXP는 TC→TP, TC→JE, TC→WI 세 경로를 모두 조절한다. 직접경로의 상세 구성은 26번 보고서와 대조한다.

EXP의 세 조절경로는 사용자가 명시적으로 요청했다. 이전 25번 문서의 탐색 유보 권고로 되돌리지 않는다.

연구 2: THR → USE → SC와 THR→SC 직접경로. 기존 보고서에 제시된 GAIL·EXP 조절 위치와 가설 방향은 원문 HTML을 다시 확인한다. 이전 대화 기록상 GAIL은 THR→USE, EXP는 USE→SC 조절이다.

핵심 문항은 총 49개다: USE4, TC4, TP3, JE3, WI5, EXP5, GAIL17, SC4, THR4. 공유 변수는 통합 설문에서 중복 질문하지 않는다.

척도와 기준업무

  • v0.9는 기존 판본으로 보존한다. v0.9.1 이후 7점 조정 흐름을 유지한다.
  • 최신 방향은 척도 문항 7점, EXP만 6점이다. 명목형·방향형 질문까지 모두 7점으로 바꾸지 않는다.
  • 7점이 PLS-SEM에서 항상 우월하다는 주장은 검증되지 않았다.
  • REF_JOB은 복수선택이다. 인하우스와 에이전시를 구분한다.
  • REF_MAIN은 후속 질문의 단일 기준업무다.
  • REG_USE·AI_START는 제거했다. 정확한 시작 연월을 기억하도록 강요하지 않는다.
  • TC·SC의 지난 1주 준거와 WORK_WEEK의 역할을 원척도와 연결해 설명한다.
  • WORK_WEEK은 AI 사용빈도나 숙련도를 측정하는 질문이 아니다. 기준업무를 실제 수행했는지 확인하는 질문이다.

보조 질문

  • ACT1–4는 기획·탐색·제작·수정 활동별 AI 사용 현황이다. 핵심 잠재변수에 자동 편입하지 않는다.
  • ACT의 전혀 사용하지 않음은 활동을 했지만 AI를 쓰지 않은 경우다.
  • 활동 자체를 수행하지 않음은 구조적 비해당이다. 0점·1점으로 합치지 않는다.
  • JE_DIR은 업무범위 변화의 방향을 확인한다. JE의 잠재변수 점수에 자동 합산하지 않는다.
  • BG4·BG5는 사용 도구·기능의 기술통계용이다. 다른 변수와 억지로 연결하지 않는다.
  • INC_AI는 단일 범주형 보조 결과다. 잠재척도의 신뢰도 검증 대상으로 설명하지 않는다.

최근 한국어 문구 기록 — 온라인 재확인 필요

  • WI1: 업무를 수행할 시간이 충분한 경우가 점점 줄어들었다.
  • WI3: 업무 강도가 높은 시기와 다음 시기 사이의 간격이 짧아졌다(줄어들었다).
  • WI4: 두세 가지 일을 동시에 해야 하는 경우가 더 잦아졌다. 예: 점심 먹기, 이메일 쓰기, 전화 통화하기.

현재 문구와 개선 제안을 나란히 표시한다. 추출 단계에서 문구를 조용히 바꾸지 않는다.

INC_AI

현재 질문: [INC_AI] 생성형 AI를 업무에 활용한 것이 현재 귀하의 디자인 업무소득에 어떤 영향을 미쳤다고 생각하십니까?

  1. 생성형 AI 덕분에 현재 디자인 업무소득이 늘었다
  2. 생성형 AI는 현재 디자인 업무소득에 영향을 미치지 않았다

7. 반드시 포함할 검토 쟁점

  1. 원척도 근거와 현재 번안의 검증은 다르다. 문항 수와 응답점수 변경만으로 타당도를 승계하지 않는다.
  2. JE는 신규 개발 후보다. TC와 내용이 겹치는지 확인한다. 확대와 재배치를 구분한다.
  3. USE가 정보·아이디어·문제해결에 치우쳤는지 확인한다. ACT가 생산 활동을 묻더라도 USE의 내용타당도를 자동 보완하지 않는다.
  4. TP는 지각된 생산성 기여다. 객관적 성과로 쓰지 않는다.
  5. WI는 강도 증가에 대한 응답이다. 낮은 점수를 업무강도 감소로 단정하지 않는다.
  6. EXP는 자기평가 전문성이다. 근속연수·객관적 실력·AI 도입 이전 실력과 동일하지 않다. 6점 원척도의 문항별 앵커를 확인한다.
  7. GAIL은 5영역 17문항이다. 고차요인 구성은 별도 측정모형 논증이 필요하다.
  8. THR은 대체 가능성 인식과 걱정의 내용이 섞였는지 확인한다.
  9. 기간은 일상적 사용·지난 1주·AI 첫 업무사용 전후 비교 등이 혼재한다. 각 준거를 표로 정리한다.
  10. 횡단 자기보고에서는 역인과와 공통방법 편향을 배제하지 못한다. 모형 화살표를 인과 입증으로 설명하지 않는다.
  11. 비해당 보기: 과거 로그는 JE3·WI5·GAIL_EC4와 ACT4개를 선택형 예외 7문항으로 기록했다. 이후 화면 기록에는 앞의 세 문항이 선형처럼 나타난 의심이 있다. 실제 현재 형식·보기와 미리보기를 다시 확인한다. 아직 오류로 확정하지 않는다.
  12. 문항 수는 고유 코드로 센다. 편집 화면의 포커스 영역이 같은 질문을 반복할 수 있다.

분석 계획에는 결측 유형, 척도 코딩, 측정모형, 조절효과, 간접효과, 대안모형을 구분한다. 채택기준의 수치가 필요하면 공식 근거를 확인한 뒤 입력한다. 아직 없는 신뢰도·타당도 결과나 파일럿 결과를 만들지 않는다.

8. 질문 목록 — 자료 확인과 사용자 결정 구분

먼저 자료로 답할 질문

  • 온라인 v0.93의 69개 문항과 실제 보기·필수 여부는 무엇인가?
  • JE_NEW·JE_LOST 제외 상태가 현재 설문과 최신 기록에 일치하는가?
  • JE3·WI5·GAIL_EC4의 비해당 보기가 실제로 응답 가능한가?
  • EXP 각 문항의 원문 앵커와 현재 라벨은 어떻게 다른가?
  • 각 문항의 영문은 원논문 직접 문구인가, 이전 연구자가 만든 번안 영어인가?
  • WORK_WEEK과 TC·SC 기간은 원논문에서 어떤 역할을 하는가?
  • 소득 문항의 원문 페이지와 현재 사본의 페이지 번호가 일치하는가?

자료 확인 후 필요한 경우 사용자에게 물을 질문

  1. 현재 문구를 보존한 정리본과 수정 권고안을 분리할까요, 승인한 수정까지 새 버전에 반영할까요? - 기본 진행: 현행 보존 + 별도 권고. 온라인 원본은 변경하지 않는다.
  2. ‘최종본’은 전문가·인지면담용 확정 정리본인가요, 실제 배포본까지 원하시나요? - 기본 진행: 검증 전 정리본. IRB·분기·저장 미검증 상태로 배포하지 않는다.
  3. JE·WI처럼 회상 비교가 필요한 문항에서 비교 불가능 응답자는 어떻게 처리할까요? - 먼저 현재 분기와 준거를 정리한 뒤 선택지를 제안한다.
  4. 전문성 문항의 원문 앵커를 모두 확보하지 못하면 현재 대칭 라벨을 예비검증 대상으로 유지할까요? - 불확실성을 숨기지 않고 채택 조건으로 남긴다.

이미 결정한 EXP 세 조절경로, BG4·BG5의 보조 역할, REF_JOB 복수선택, INC_AI 세 보기는 재질문하지 않는다. 위 질문 전부에 답할 때까지 문서 제작을 중단할 필요는 없다.

9. 다음 세션 실행 순서와 산출물

  1. 현재 설문을 읽기 전용으로 추출한다. 코드·섹션·문구·보기·형식·필수·분기를 기록한다.
  2. 로컬 판본과 차이를 표로 만든다. 온라인 수정 권고와 실제 수정 이력을 구분한다.
  3. 원문 PDF와 기존 영문 대조 자료를 확인한다. 핵심 페이지를 캡처한다.
  4. 새 폴더에 설문·대조표·근거·검토보고서·모형 설명을 만든다.
  5. 문항 수, 대응 관계, 링크, 이미지, HTML 화면을 검수한다.
  6. 인용 명세서와 세션 로그를 남긴다. 사용자에게 시작 HTML을 연다.

파일명은 제안이다. 기존 파일을 덮어쓰지 않는 범위에서 조정할 수 있다. 논문 사본은 로컬 연구용으로 정리한다. 공개 웹에 PDF를 게시하지 않는다.

모형 설명 HTML에는 연구 1·2 각각 다음 내용을 담는다.

  • 핵심질문과 연구목표.
  • RQ와 RQ별 설정 이유.
  • 핵심변수 정의, 필요성, 경로의 논리.
  • 핵심변수만 표시한 SVG.
  • 보조변수까지 포함한 전체 조사 구성 SVG.
  • 보조변수의 분석 용도. 가설 경로가 없으면 실선 인과 화살표를 그리지 않는다.
  • 대안 설명 최소 두 가지, 반대 가설의 근거, 미확인 사항.

검토보고서는 내용·번역·응답척도·기간·표본 적합성·측정모형·구현을 나눠 판정한다. ‘원문 확인’, ‘번안 검토 필요’, ‘인지면담 필요’, ‘실증검증 미완료’를 별도 표시한다.

10. 완료 판정

  • 현재 온라인 설문의 고유 코드 전부가 정리본과 코드북에 대응한다.
  • 49개 핵심 문항과 나머지 선별·보조 항목을 구분한다.
  • 영어 원문과 연구자 작성 영어를 구별한다.
  • 캡처마다 읽을 수 있는 원문, PDF 식별정보, 페이지 번호가 있다.
  • 근거 파일과 이미지 링크가 모두 열린다.
  • 모형의 EXP 세 조절경로와 보조변수 역할이 사용자 결정에 맞는다.
  • 새 HTML을 넓은 화면과 좁은 화면에서 확인한다.
  • 검증 미완료와 온라인/로컬 차이를 숨기지 않는다.
  • 기존 판본 보존, Google 비게시 유지, 실제 응답 데이터 불필요 접근 금지를 지킨다.

11. 안전·작업 메모

루트 AGENTS.md를 따른다. 파일 삭제·덮어쓰기 전 확인하고, 원본 폴더를 수정하지 않는다. 자격증명 파일에 접근하지 않는다. 새 의존성·외부 네트워크 사용은 적용 지침과 권한을 확인한다.

PDF 캡처 작업에는 사용 가능한 PDF 스킬을 읽고 적용한다. 인용은 원문 직접 확인 후 입력한다. 모든 캡처는 새 패키지의 docs/assets/ 안에 둔다. 확인되지 않은 근거는 미확인으로 기록한다.

이 문서는 인수인계용이다. 새 패키지 제작, 온라인 재검수, 원논문 재확인, 경험적 타당도 검증은 이 문서 작성 시점에 완료되지 않았다.
