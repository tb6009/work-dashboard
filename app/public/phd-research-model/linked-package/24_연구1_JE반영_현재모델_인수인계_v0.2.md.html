연구 1 현재 모델과 인수인계

2026-10-05 / v0.2 / 개념모형. 최종 검증된 설문이 아니다.

현재 기준

  • 연구 목적: 생성형 AI 활용 디자이너의 과업재설계와 생산성 기여·직무확대·업무강도 증가의 관계를 살핀다.
  • 주경로: USE → TC → TP, JE, WI(IDS). 세 결과변수는 병렬 배치한다.
  • GAIL은 USE → TC 경로를 조절한다.
  • EXP는 TC → TP, TC → JE, TC → WI 경로를 조절한다.
  • INC_AI는 별도 보조 결과다. 주모형에서 소득으로 이어지는 경로를 확정하지 않았다.
  • TV는 JE로 이름만 바꾼 것이 아니다. 현재 수준인 TV 대신 회고적 확대인 JE를 결과 후보로 채택했다.
  • 이번 연구 1 그림에 TV·SV·IWB·SC·접근/회피 구분을 넣지 않는다. 연구 2는 변경하지 않았다.
  • 기존 설문에서 TV·SV 문항을 실제 삭제할지는 별도 결정한다. 이번 작업은 그림과 인수인계만 변경했다.

변수 정의와 미검증 사항

코드 정의 남은 검토
USE 업무에서 생성형 AI 사용 측정 방식과 기간 정합성
TC 과업재설계 행동 TC1의 과업 추가와 JE 중복
TP 생성형 AI의 지각된 생산성 기여 순수 효율 또는 실제 생산성 변화와 동일시 금지
JE AI를 업무에 활용하기 이전 대비 담당 과업 종류·범위의 지각된 확대 연구자 작성 후보. 검증된 기존 변화척도가 아님
WI 업무강도 증가. IDS의 5문항 하위척도 후보 원문 최근5년 기준, 프리랜서에게 직원 감소 문항 적합성
INC_AI 생성형 AI의 지각된 소득 영향 사용자 제안5점은 원문 응답과 다름. 보조 분석

JE 기준 시점은 AI 업무 사용 이전으로 합의했다. ‘정기적으로 활용하기 시작하기 전’은 구체화 제안이며 인지면담으로 확인한다. AI 사용 전후라는 시간 비교는 AI 인과효과의 증명이 아니다.

다음 작업

  1. 기존 TC1과 JE 후보의 개념·문항 중복을 우선 검토한다.
  2. JE 기준 시점·응답방식·축소 및 변화 없음 처리를 확정한다.
  3. TP·JE·WI와 TC의 측정 기간을 검토한다.
  4. 전문가 내용 검토, 번역 대조, 재직자·프리랜서 인지면담을 진행한다.
  5. 파일럿에서 문항 분포와 측정구조를 확인한다. 조사 전 분석 계획을 정한다.

효율만 증가, 효율과 강도 동반 증가, 강도 증가와 보상 동반 증가를 모두 열어둔다. 소득 증가가 없다는 응답만으로 부담 증가를 입증하지 않는다. 횡단 설문으로 TC와 결과의 인과 방향을 확정하지 않는다.
