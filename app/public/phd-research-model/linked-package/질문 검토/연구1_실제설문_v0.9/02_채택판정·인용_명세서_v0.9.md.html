실제 설문 채택 판정과 인용 명세서

2026-10-05 / 연구 1 v0.9. 사용자 후속 지시: EXP가 TC→TP·JE·WI 세 경로를 각각 조절한다.

1. 판정

실제 문항·응답 선택지·분기·코드북을 작성했다. 현재 채택 수준은 ‘연구자가 참여설명을 완료한 인지면담용 문항지’다. 인지면담 후 파일럿으로 진행한다. 본조사 배포와 검증 완료 판정은 보류한다.

문항 원문과 범주 확인은 수행했다. 전문가 내용평가, 대상자 인지면담, 실제 데이터의 요인구조·신뢰도·판별성·측정동일성 검증은 이번 작업에서 수행하지 않았다. 데이터가 없어 해당 수치를 계산할 수 없다. 기존 기록에서도 완료된 결과를 확인하지 못했다.

모형에 EXP 조절을 포함하는 결정과 조절효과가 실증적으로 지지되는지는 별개다. 이번에는 사용자 지정대로 세 조절경로를 모두 포함한다. EXP를 탐색 후보로 낮춘 v0.3 권고는 이번 구성에 적용하지 않는다.

2. 이번 설문에서 실제로 선택한 사항

변수 실제 구성 원문 대조 현재 채택 수준
USE 기존 국문 4문항·7점·평소 준거 정보·아이디어 중심 4문항 확인 인지면담 후보. 제작 전반의 사용량으로 해석하지 않음
TC 기존 국문 4문항·지난 1주·5점 Bindl의 문항·기간·범주 확인 인지면담 후보. v0.8의 7점을 5점으로 복원

이 문서는 5점판 v0.9를 명세한다. 7점판 v0.9.1은 별도 버전이다. TC·WI는 양끝만 언어 라벨을 표시했다. 원문에서 확인하지 못한 중간 라벨을 원라벨로 만들어 넣지 않았다. TP의 한국어 기여 라벨은 원문 의미에 맞춘 번역이다. EXP의 한국어 전체 라벨은 기존 초안의 임시 번안을 유지했다. 2018 공식 라벨이라고 표시하지 않는다.

원문에 없는 ‘판단 어려움·해당 없음’을 추가한 것은 적합성 진단을 위한 설계 변경이다. 모든 블록의 이 변경을 기록한다. 이 응답은 척도 중간점에 포함하지 않는다.

JE-A를 채택한 이유는 현재 모형의 ‘확대’ 정의를 유지하기 위해서다. 축소 여부는 JE_DIR로 별도 확인한다. JE_DIR·JE_NEW·JE_LOST를 JE1–3에 합산하지 않는다. JE3은 프로젝트 단위 업무에 해당하지 않을 수 있어 내용 검토 대상이다.

현재 TC는 AI를 이용한 행동만 묻지 않는다. TP는 AI 기여를 묻고, JE·WI는 AI 활용 이전과 비교한다. 세 결과의 점수를 직접 비교하거나 차감하지 않는다. TC의 1주를 유지했으므로 장기 변화를 발생시킨 매개로 해석할 수 없다.

3. 채택 게이트

‘예비 문항 채택’과 ‘본조사 채택’을 구분한다. 아래 수치 중 연구자 운영기준은 보편적 표준이나 검증된 법칙이 아니다.

게이트 통과 기준 현재 결과 미통과 시 조치
G0 추적성 기존 척도는 문항·문두·응답의 원문 위치, 변경사항 기록. 새 문항은 개발 표시 부분 통과. EXP 라벨 불일치 남음 EXP 원응답 확보 또는 연구자 번안 응답으로 별도 타당화
G1 개념·내용 관련성·포괄성·이해가능성을 확인. 전문가 6명 중 최소 5명이 각 문항의 적절성에 동의하는 내부 기준 제안 미실시 수정 이유를 남기고 재검토. 점수만으로 누락 개념을 무시하지 않음
G2 인지면담 직원·프리랜서와 경력 차이를 포함. 최종 회차에서 기준 시점·TC/JE/WI 의미·앵커에 관한 중대한 오해가 미해결로 남지 않음 미실시 문항 수정 후 추가 면담. 단순 문장 교정으로 통과 처리 금지
G3 적용성·분기 의도된 구조적 결측을 제외하고 집단별 판단불가·해당없음·누락 확인. 어느 집단에서든 문항 비실질응답 20% 초과 시 재검토하는 내부 기준 미실시 WI5·JE3·GAIL_EC4 우선 검토. 낮은 수치라도 체계적 오해는 수정
G4 측정구조 반영형으로 채택할 근거를 먼저 확정. 구조·부하량·신뢰도·수렴·판별성 함께 평가 미실시 잘 맞는 결과를 얻기 위한 임의 삭제 금지. 의미 변경 시 새 버전
G5 TC–JE 구분 내용 구분 + 공동 측정모형 + 판별성 기준을 함께 충족 미실시 TC→JE 확증 경로 보류. 문항 재개발 또는 JE 탐색 유보를 사전 결정
G6 표본·분석 GAIL 1개 및 EXP 3개 상호작용을 포함한 검정력·추정법·다중검정 계획 사전 확정 미실시 자료를 모은 후 유의한 조절만 선택하지 않음
G7 배포 준비 참여설명·연구자 연락처·자료관리·기관 절차 확정. 번안 사용조건 확인 미확정 온라인 본조사 게시 보류

G1의 내용 평가 영역은 COSMIN의 관련성·포괄성·이해가능성을 참고한다. COSMIN은 환자보고결과 도구에서 개발된 방법론이다. 여기서는 점검 틀로 활용하며 디자인 직무 척도의 자동 인증 기준으로 적용하지 않는다. COSMIN 공식 설명.

G4·G5에서 PLS의 반영형 측정을 선택할 경우 다음을 사전 검토 기준으로 사용한다. 부하량 0.70 이상, 내적 일관성 지표 0.70 이상, AVE 0.50 이상을 점검한다. TC–JE는 HTMT 0.85 이하를 우선 목표로 두며, 0.85 초과이면 내용 중복과 구조를 추가 검토한다. 0.90 이상은 통과 처리하지 않는다. HTMT의 편향보정 신뢰구간 상한이 0.90 미만인지도 확인한다. 경계값만으로 타당성을 확정하지 않는다. SmartPLS 기준표 · HTMT 추론 안내.

이 수치는 모든 측정 유형에 공통 적용하지 않는다. GAIL의 고차구조 및 각 변수의 반영형/형성형 결정을 먼저 한다. CFA를 사용한다면 해당 추정법과 모형에 맞춘 별도 적합도 평가계획을 정한다. JE 3문항 단독 1요인 모형은 일반적 식별 설정에서 자유도 0일 수 있으므로 좋은 적합도만으로 검증 완료라 하지 않는다. TC·JE 공동 구조와 외적 관련성을 함께 확인한다.

4. 확정한 분석 대상과 미확정 사항

TC = a0 + a1 USE + a2 GAIL + a3 USE×GAIL + 사전 지정 공변량 + 오차
TP = b0 + b1 TC + b2 USE + b3 EXP + b4 TC×EXP + 사전 지정 공변량 + 오차
JE = c0 + c1 TC + c2 USE + c3 EXP + c4 TC×EXP + 사전 지정 공변량 + 오차
WI = d0 + d1 TC + d2 USE + d3 EXP + d4 TC×EXP + 사전 지정 공변량 + 오차

GAIL×USE 및 EXP×TC는 분석에서 생성한다. EXP를 고·저로 임의 이분화하지 않는다. 조절 세 경로는 방향을 미리 양수로 단정하지 않는다. 숙련이 생산성 기여를 높이거나 AI의 한계효과를 낮출 수 있다. 숙련이 업무강도를 완충하거나 추가 업무 배정을 늘릴 수도 있다.

조건부 간접 관련성을 제시한다면 (a1+a3GAIL)(b1+b4EXP) 등의 형태다. 최근 TC와 회고적 변화의 시간 불일치로 인해 인과적 매개 검증이라는 명칭을 사용하지 않는다. 주 분석의 초점은 조절된 관련성이다. 인과적 매개가 필수 목표라면 별도 종단 설계가 필요하다.

EXP가 자기평가 능력이라는 점, GAIL도 사용으로 발달할 수 있다는 점을 해석에 반영한다. 조절변수의 현재 점수를 사용 이전 능력으로 간주하지 않는다.

5. 분기·코딩 규칙

  • 동의하지 않음, 유급 디자인 업무 없음, AI 사용 경험 없음이면 종료한다.
  • 최근 3개월 미사용 경험자는 설문 참여를 허용하되 S2로 구분한다. 본조사 주분석 집합은 사전 지정한다.
  • ‘반복적 활용’ 시점이 있고 사용 전 유급 디자인 경험이 있으며 비교 가능할 때만 JE·WI를 제시한다.
  • 사용 전 경험이 없거나 비교 불가한 사람의 JE·WI는 구조적 결측이다. 0·중립·변화 없음으로 대체하지 않는다.
  • 지난주 업무를 하지 않았다면 TC는 구조적 결측이다. TC=최저점으로 코딩하지 않는다.
  • 직원·프리랜서를 겸하면 S3에 복수선택하고, REF_JOB로 답할 업무를 하나 정한다.
  • WI5의 해당 없음은 원자료에 남긴다. 전원 공통 4문항판을 이미 검증한 것처럼 점수화하지 않는다.
  • 척도 응답은 선택지의 숫자를 점수로 사용한다. 판단 어려움=DK, 해당 없음=NA, 응답 거절=REF, 분기 미제시=SKIP로 별도 기록한다. v0.9와 v0.9.1의 점수를 단순 합산하지 않는다.
  • ACT는 v0.8과 반대 방향이다. 새 버전은 1=전혀 안 씀, 4=매우 자주다. 이전 자료를 합칠 때 일반 응답 1–4에만 새 값=5−기존 값을 적용한다.
  • INC_AI는 감소=-1, 영향 없음=0, 증가=1로 보관할 수 있지만 범주형으로 분석한다. 연속형 등간 점수라고 가정하지 않는다.
  • GAIL은 5개 영역을 보존한다. 17문항 총평균을 검증 없이 확정하지 않는다.
  • 인지면담 단계에서는 척도 총점으로 가설검정을 하지 않는다. 이후 합산·결측 허용 규칙은 선택한 측정모형과 함께 확정한다.

총 63개 응답 항목 중 핵심 후보는 42개다. ACT4, JE 진단3, 선별·배경·의견14개를 더했다. 실제 응답 수는 분기로 달라진다. 이 문항지는 연구 1 단독본이다. 연구 2의 SC·THR과 공유 변수 통합은 별도이며, 원 통합설문에서 삭제하지 않았다.
