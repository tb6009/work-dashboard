2. 직접 출처와 최초 개발 출처의 구분

TC·SC는 Bindl 등(2019)의 촉진형 차원을 직접 대조했다. 일반 TC 정의의 고전 연구를 직접 읽은 것으로 표시하지 않는다. USE는 X. Zhang 등(2026)의 Table 1에 실린 네 문항을 직접 대조했다. 해당 논문이 참조한 Sun 등(2022)·Zhang 등(2019)의 최초 개발 계보는 추가 원문 확인이 필요하다. EXP는 2018년 단축판을 사용하며, 단축판 이전 장척도를 직접 검토한 것으로 쓰지 않는다.

5. 제출 전 확인 사항

EXP의 공식 응답 앵커, WI5의 혼자 일하는 응답자 적합성, THR3의 번안 범위, GAIL 총점 사용, JE의 판별타당성이 남아 있다. 기존 척도의 신뢰도 수치를 현재 한국어 설문의 신뢰도로 보고하지 않는다. 원척도에서 조절변수로 사용하지 않았더라도 이론적 근거를 제시해 새 위치를 검토할 수 있으나, 척도 출처만으로 새 조절경로가 정당화되었다고 쓰지 않는다.
