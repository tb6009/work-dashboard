현행 설문은73문항·핵심49문항이다. END_DIFF는 ACT4 다음, 최근3개월 사용자에게 제시하며 PRE_AI·COMPARE 분기에 묶지 않는다. WI·ACT 합산 제외. 네 WIA 후보는 현행에서 제외. 추가 인지면담은 수행하지 않는다. 아래 이전 실행 명세 중 면담 제안과 충돌하는 부분은 이 절로 대체한다.

 종료 판단의 탐색적 분석·보고 원칙

END_DIFF는 핵심 모형을 해석하는 보조자료로 사용한다. 문항 응답의 분포와 유효 응답 수를 보고하고, WI·EXP와의 관련성을 탐색한다. WI 관련성은 회고 비교 적격 공통 표본에서, EXP 관련성은 최근3개월 AI 사용 적격 표본에서 분석한다. 분모와 결측을 각각 공개한다. 단일 순서형 문항의 특성을 고려해 Spearman 상관과95% 신뢰구간을 기본 탐색안으로 두고, 두 관련성 검정을 한 군으로 묶어 Holm 보정 전후 결과를 보고한다. 확정된 인과 가설 검정으로 제시하지 않는다.

결과의 유의 여부와 관계없이 두 관련성을 모두 보고한다. 단일 문항에 Cronbach의 알파를 산출하지 않는다. 이 문항을 추가 통제변수로 자동 투입하지 않는다. TP·JE 관련성이나 추가 하위집단 분석은 이번 사전 탐색안에 포함하지 않는다. 필요하면 계획 변경을 기록하고 추가 탐색임을 표시한다.

방법에는 개발 경위·전체 문구·응답척도·대상을, 결과 또는 부록에는 분석 결과를 제시한다. 논의에서는 해당 응답 수준의 관련성으로 해석한다. 종료 판단이 WI의 원인이라는 주장, 정보 과부하가 기제라는 주장, 실제 소요시간이 늘었다는 주장은 하지 않는다. 종료 판단이 어렵지만 WI는 높지 않은 경우와 전문성에 따른 뚜렷한 차이가 없는 경우도 허용한다. 이 보조문항을 제외해도 핵심 연구의 질문과 결론은 성립해야 한다.

## 1. 모집과 분석의 결정표

| 항목 | 현재 계획 | 확정 조건 |
|---|---|---|

| 목표 표본 | 미확정 | 여덟 상호작용·측정구조·최소 관심 효과의 검정력 검토 |

검정력 검토는 최소 관심 효과·결측·상호작용 크기의 여러 조건을 사용한다. 유효 표본은 분석별로 다르므로 가장 제한적인 회고 비교·공통 표본의 수를 별도로 계획한다. 필요한 유효 수가 N이고 적격률 q, 자료 사용 가능 비율 r이면 모집 수의 검토값은 N/(q×r)이다. N·q·r은 아직 추정하지 않았다. 문항 수의 배수만으로 목표 표본을 정하지 않는다.

## 2. 제시·종료·분석 흐름안

1. CONSENT가 비동의이면 설문을 종료한다.
2. S1이 아니오이면 본조사 대상에서 제외한다.
3. S2가 경험 없음이면 경험자 대상 핵심 설문을 종료한다.
4. 최근 미사용 경험자는 예비조사에서 별도 표시한다.
5. WORK_WEEK가 아니오이면 TC·SC를 제시하지 않는다.

이 흐름은 본조사 구현안이다. 현재 온라인 폼이 이대로 작동한다고 확인한 기록은 아니다. 분기 테스트에는 동의/비동의, 비경험/최근 미사용/최근 사용, 지난주 업무 없음, 사용 전 업무 없음, 비교 불가 사례를 포함한다. BG4·BG5·BG_USEMODE의 단독 선택 안내와 복수 선택 상충도 확인한다.

## 3. 코딩과 점수화

원문항 코드북은 보존한다. 별도 [보기·결측 코딩안 TSV](13_분석코딩안_20261017.tsv)에 73개 문항의 선택지 코드와 정리된 조건을 기록했다. 코드 부여는 분석 준비안이며 이미 수집한 자료의 실제 코드라고 주장하지 않는다.

- 순서형 응답은 표시된 숫자를 그대로 저장한다. EXP는1–6, 핵심 나머지 척도는1–7이다.
- 일반 단일선택은 보기 순서1부터 코딩한다. JE_DIR도 순서1–5이며 등간성을 가정하지 않는다.
- 복수선택은 보기별0/1로 저장한다. 질문 미제시·무응답은 모든 보기에0을 넣지 않는다.
- 경력은0이상 숫자다.0은1년 미만을 포함한다. 자유서술은 비식별 처리한다.
- 점수 값과 결측 사유를 별도 열에 저장한다. 결측 사유는 SKIP, NA_EXPANSION, OMIT, INVALID, NOT_APPLICABLE다.
- 경험 없음 선택은 NA_EXPANSION이다. WI5의 적용 불가능은 해당 사실을 식별했을 때만 NOT_APPLICABLE로 기록한다.
- 원자료에 없는 WI5 해당 없음 선택지를 새로 있었다고 기록하지 않는다.
- 분석 전 결측 점수는 NA로 변환한다. 결측 사유 문자열을 척도값에 혼합하지 않는다.

완전응답 평균의 검토안은 USE4·TC4·SC4·TP3·JE3·WI5·EXP5·THR4에 적용한다. 현재 문항 방향을 그대로 사용한다. GAIL_BO3·PE3·QE3·IA3·EC5의 차원 평균은 차원 내 완전응답을 기본으로 검토한다. 최종 총점 사용은 요인구조 검토에 따른다. 각 평균은 원척도 범위를 유지한다. 단일 JE_VOL·JE_IMP는 합산하거나 신뢰도 계수를 계산하지 않는다.

일반 결측에는 추정법에 맞는 처리를 정한다. 완전사례·부분 평균·다중대치 등을 분석 결과에 맞춰 선택하지 않는다. 부적격·미제시 자료는 단순 일반 결측으로 보충하지 않는다. WI 적용 가능 집단에서만 점수가 유효하다면 그 집단을 명시한다. 근로형태 간 비교는 내용 적용과 측정 비교 가능성을 검토한 뒤 수행한다.

## 4. 문항 검토와 남은 측정 한계

추가 인지면담은 수행하지 않는다. 기존 사전인터뷰를 새 문항 타당화로 간주하지 않는다. 원문 대응·문항 수·분기·척도 앵커는 문서와 화면에서 확인한다. 응답자 이해의 적합성은 미검증으로 남는다. WI5·JE 자발/부과 구별·THR 번안·GAIL 총점의 문제를 자료 분석만으로 해결했다고 쓰지 않는다. 자료에서 측정구조·결측·분기 상충을 검토하고, 사전에 정한 처리 및 결과 공개 원칙을 따른다.
