# 화면·실제 인쇄 검토 — 2026-10-18

## 검토 조건
Chrome headless 실제 렌더링. 화면 1440×1000 및 390×1000. 인쇄 A4 세로, 배율 100%, 머리글·바닥글 없음, 문서 CSS 페이지 규격 우선, 배경 출력. 설문은 분기 미적용 전체 문항 상태이며 한영 병기와 한국어만 보기 각각 출력했다.

## 실제 출력
| 문서 | 쪽수 | 판정 |
|---|---:|---|
| 3페이지 요약본 | 3 | 세 페이지 모두 내용 존재. 각 페이지 scrollHeight와 고정 높이 일치. 잘림 미발견 |
| 전체 계획서 | 13 | 제목/표 분리와 출력 여백 개선 필요 |
| 설문 한영 병기 | 10 | 마지막 10쪽에는 종료 안내만 있어 불필요한 페이지 발생 |
| 설문 한국어 | 8 | 마지막 쪽에 문항과 안내 존재. 빈 페이지 없음 |

## 발견 사항과 수정 방향
1. 전체 계획서 모바일 가로 넘침: 화면 390px에서 문서 폭 718px. 표 최소폭과 긴 분석식/문자열을 점검하여 표 영역 안의 스크롤 및 식 줄바꿈 적용 필요.
2. 전체 계획서 인쇄 안전 여백 부족: 출력 본문과 표가 종이 좌우 가장자리까지 배치됨. A4 인쇄용 @page 여백을 명시하고 여백 적용 후 쪽수 재검증 필요.
3. 제목과 표 분리: 전체본 3쪽 끝의 ‘2.3.2 GAIL·EXP의 조절경로’ 제목 아래 표가 다음 쪽에 시작함. 제목과 표 머리글/첫 행을 묶는 페이지 분할 규칙 필요.
4. 표 이어짐: 전체본의 긴 표가 다음 쪽으로 이어짐. 표 머리글은 반복되지만 일부 행은 경계에서 분리되어 읽기 불편. 행 분할 방지와 페이지 여유 점검 필요.
5. 설문 구역 제목 분리: 한영 병기 3쪽 끝에 ‘6. 업무강도의 변화’와 안내만 남고 문항은 다음 쪽으로 넘어감. 제목·안내·첫 문항을 함께 배치할 필요.
6. 설문 한영 병기 마지막 쪽: 10쪽에 종료 안내만 출력됨. 종료 안내 여백 축소 또는 마지막 문항과 묶기 필요. 한국어 8쪽은 빈 페이지가 아님.
7. 요약본 모형: 이미지와 화살표는 잘리지 않지만 변수의 한글 설명·범례가 작음. 본문보다 작은 보조 글씨 확대, SVG 내부 여백 및 배치 개선을 권장. 모바일에서는 확대 열기 필요.
8. 설문 모바일 제목: 제목의 마지막 ‘험’ 한 글자만 다음 줄로 떨어짐. 제목 줄바꿈 또는 글자 크기 미세 조정 권장. 화면 가로 넘침은 없음.

## 정상 확인
- 인덱스·요약본·설문은 390px에서 전체 가로 넘침 없음.
- 요약본은 실제 3쪽이며 빈 페이지 없음. 1쪽 하단 여유가 있어 글자를 더 줄일 필요 없음.
- 연구모형 SVG 2개 정상 로드.
- 설문은 실제 인쇄에서 응답 보기가 표시됨. 한국어/한영 병기 전환에 따라 출력 분량이 변경됨.
