## 원칙

1. 발췌는 `pdf/`에서 직접 확인한 문장만 쓴다. 쪽 번호는 PDF 파일 쪽수다.
2. 원문을 확보하지 못한 문헌은 `06`에 올리고 발췌하지 않는다. 계보도에는 「미확보」로 표시한다.
3. 프리프린트·워킹페이퍼로 읽은 논문은 출판본과 문구가 다를 수 있다. 인용 전 출판본 대조가 필요하다.
4. Q1 표시는 저널 명성에 따른 **추정**이다. SJR/JCR 분위는 이번에 직접 조회하지 않았다. 투고 전 확인한다.
