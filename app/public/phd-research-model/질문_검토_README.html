질문 검토

최신: TV·SV 추가 자료집 v0.5

  • 전체 설문 v0.5: TV4·SV4를 TC·SC 뒤에 추가. 본문80코드, 선택3 포함83코드.
  • 최신 Excel: 확인문항62개, 연구자작성21개. 기존 자료 및 검토 메모 보존.
  • TV·SV 출처와 모형 비교 메모.
  • TV·SV는 별도 변수로 수집. 중간 경로는 비교 후보이며 최종 경로 확정은 아님. 원5점→7점 번안 기록.

이전 v0.4 기준 자료: 원문·영한 대조·캡처 자료집

  • 확인 문항 54개: 핵심50 + 소득영향1 + 선택후보3. 선택후보는 채택 문항이 아니다.
  • 연구자 작성21개: 선별·배경17 + ACT4. 원척도 검증완료로 분류하지 않음.
  • 캡처: docs/assets. 보유 PDF 직접 렌더링.
  • 챕터별 Markdown: 챕터 폴더.
  • 확인된_질문지_영한대조.xlsx: 확인 문항, 연구자 작성, 원응답·문두 3개 시트.
  • 01_질문검토_인용_명세서.md: 문항별 출처·페이지·상태.
  • 02_우선검토사항.md: 수정·추가 확인할 항목.
