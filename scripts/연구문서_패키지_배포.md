# 연구 문서와 연결 자료를 함께 배포하기

앱 폴더에서 `npm run build:research`를 실행한다.

- 입력: 연구모델 정리/질문 검토/최종설문/04 연구모형 설명 HTML.
- 출력: `app/public/phd-research-model/linked-package/` 전체.
- 기존 대표 문서 주소도 새 패키지를 참조하도록 함께 생성한다.
- `manifest.json`에는 포함 파일, 미확보 링크, 외부 주소를 기록한다.
- 공개 폴더 전체를 기존 대시보드 배포에 포함한다. HTML 하나만 업로드하지 않는다.
- 다른 정적 호스팅에서는 linked-package 폴더 전체를 올리고 index.html을 연다. ZIP 업로드를 지원하지 않는 서비스는 압축을 먼저 풀어야 한다.
- Google Forms는 외부 링크로 유지한다. 편집본에는 권한이 필요하며 응답자용 주소를 추정해서 만들지 않는다.
- 선행논문 로컬 PDF는 공개하지 않는다. 제외된 링크는 비공개 원문으로 표시한다.
- marked는 Codex 번들에서 불러온다. 다른 컴퓨터에서는 `PHD_MARKED_PATH`에 설치된 marked 경로를 지정한다. 생성된 패키지를 보는 데 Node나 marked는 필요 없다.

이 작업은 로컬 배포 파일 생성까지만 수행한다. 실제 원격 배포는 별도 단계다.
